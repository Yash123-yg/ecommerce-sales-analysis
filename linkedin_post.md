# LinkedIn Post

🚀 **Completed My PostgreSQL E-Commerce Sales Analysis Project!**

I’m excited to share a SQL project I built to strengthen my practical data analysis skills using **PostgreSQL**.

### 🔎 What I worked on

I analyzed customer and order data to answer 35 business-focused questions, including:

✅ Total sales and average order value  
✅ Top customers by spending  
✅ Sales by city and product category  
✅ Monthly sales trends  
✅ Customers with multiple orders  
✅ Customers who have not placed an order  
✅ Discount and order-value analysis  
✅ Customer contribution to total sales  
✅ Customer ranking within each city  

### 🧠 SQL concepts practiced

- SELECT / WHERE / ORDER BY
- GROUP BY / HAVING
- Aggregate functions
- INNER JOIN / LEFT JOIN
- CASE statements
- Date functions
- CTEs
- Subqueries
- DENSE_RANK()
- LAG()
- Running totals with window functions
- Business KPI analysis

One of the advanced analyses ranks customers by total spending within each city using `DENSE_RANK()` and a CTE.

This project helped me improve my ability to move from raw relational data to structured business analysis using SQL.

I’m continuing to build my **SQL + Excel + Data Analytics** portfolio and improve my problem-solving skills through practical projects.
